## TypeScript: ts_ls o vtsls

Hay dos servidores de TypeScript y **no debes activar los dos a la vez**:

<Cards>
  <Card icon="🟦" title="ts_ls">
    El servidor oficial. Sólido y estándar. Es el que pusiste en Mason en la lección 2.1. Perfecto para la mayoría.
  </Card>
  <Card icon="🚀" title="vtsls">
    Un wrapper con extras: mejor rendimiento en monorepos, inlay hints más ricos y más comandos. La opción "pro".
  </Card>
</Cards>

Si quieres **vtsls**, cámbialo en Mason (quita `ts_ls`, añade `vtsls`) y afínalo con inlay hints:

```lua title="lua/plugins/lang-frontend.lua"
return {
  "neovim/nvim-lspconfig",
  opts = function()
    -- Opción vtsls (si lo prefieres a ts_ls). No actives ambos.
    vim.lsp.config("vtsls", {
      settings = {
        typescript = {
          inlayHints = {
            parameterNames = { enabled = "literals" },
            variableTypes = { enabled = true },
            functionLikeReturnTypes = { enabled = true },
          },
        },
      },
    })

    -- Tailwind: reconoce clases dentro de cadenas y helpers (clsx, cva...)
    vim.lsp.config("tailwindcss", {
      settings = {
        tailwindCSS = {
          experimental = {
            classRegex = {
              { "cva\\(([^)]*)\\)", "[\"'`]([^\"'`]*).*?[\"'`]" },
              { "cx\\(([^)]*)\\)", "(?:'|\"|`)([^']*)(?:'|\"|`)" },
            },
          },
        },
      },
    })
  end,
}
```

<Callout type="info" title="Ya tienes casi todo instalado">
En la lección 2.1 añadiste a Mason: `ts_ls`, `tailwindcss`, `cssls`, `html`, `emmet_language_server`, `jsonls`. Al abrir un `.tsx` se habilitan automáticamente. Este archivo solo afina settings.
</Callout>

## Tailwind con previews de color

El LSP de Tailwind ya autocompleta clases y muestra el CSS que generan al hacer hover. Para ver los **colores** inline (un cuadradito con el color real junto a la clase), añade previews:

```lua title="lua/plugins/tailwind.lua"
return {
  "brenoprata10/nvim-highlight-colors",
  event = { "BufReadPre", "BufNewFile" },
  opts = { render = "virtual", enable_tailwind = true },
}
```

Ahora `bg-red-500` o `#89b4fa` se muestran con su color real al lado. Imprescindible para trabajar con paletas.

## CSS, HTML y Emmet

- **cssls** da completado y validación en `.css`.
- **html** hace lo propio en `.html`.
- **emmet_language_server** expande abreviaturas: escribe `div.card>ul>li*3` y con la code action / completado se convierte en el HTML completo. Funciona también en JSX.

## ESLint y Prettier

Dos enfoques para ESLint:

1. **LSP de ESLint** (`eslint` en Mason): diagnósticos en vivo y "fix on save" vía code action. Añádelo a `ensure_installed` si quieres el servidor.
2. **eslint_d vía nvim-lint** (lección 2.4): más ligero, corre el linter al guardar.

Para formatear, ya configuraste **Prettier** en conform (`prettierd` con fallback a `prettier`). Se ejecuta al guardar en JS/TS/CSS/HTML/JSON. Un `.prettierrc` en la raíz manda sobre el estilo.

## Autotag para JSX

Ya lo añadiste en la lección 2.3 (`nvim-ts-autotag`): al escribir `<div>` se cierra solo, y renombrar la etiqueta de apertura actualiza la de cierre. En React esto ahorra cientos de pulsaciones al día.

<Callout type="tip" title="package.json vivo">
Añade **package-info.nvim** (`vuki656/package-info.nvim`) para ver versiones actuales y disponibles de tus dependencias dentro de `package.json`, y actualizarlas con una tecla — el equivalente a crates.nvim pero para npm.
</Callout>

<Callout type="dios" title="Neovim para React, de verdad">
Con TS + Tailwind + autotag + previews de color + Prettier al guardar, tienes el bucle completo de React: autocompletado de props y clases, renombrado seguro de componentes con `<leader>rn`, imports automáticos, formateo instantáneo y JSX que se cierra solo. Súmale flash.nvim para saltar por componentes largos y editas interfaces más rápido que en cualquier editor gráfico.
</Callout>

2. En un `.tsx`, escribe `<div className="bg-` y mira el autocompletado de Tailwind con previews.
3. Renombra un componente con `<leader>rn` y observa cómo se actualizan los usos.
