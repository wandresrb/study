## let vs var: constantes y variables

En Swift declaras valores con `let` (constante, no cambia) o `var` (variable, puede cambiar):

```swift
let pi = 3.14159      // constante: no se puede reasignar
var contador = 0      // variable: sí se puede
contador = contador + 1

// pi = 3.15          // ❌ error de compilación: 'pi' es let
```

<Callout type="dios" title="Prefiere let siempre que puedas">
La regla de oro en Swift: usa `let` por defecto y `var` solo cuando de verdad necesites cambiar el valor. El compilador incluso te avisa si declaras un `var` que nunca cambia. Esto no es pedantería: el código con constantes es más fácil de razonar porque sabes que esos valores no se moverán bajo tus pies. Menos estado mutable, menos bugs.
</Callout>

## Los tipos básicos

```swift
let entero: Int = 42
let decimal: Double = 3.14
let texto: String = "Hola"
let verdadero: Bool = true
```

## Inferencia de tipos

Swift **deduce** el tipo por el valor, así que casi nunca necesitas anotarlo:

```swift
let edad = 30          // Swift infiere Int
let altura = 1.75      // Swift infiere Double
let nombre = "Ana"     // Swift infiere String
let activo = true      // Swift infiere Bool
```

Anota el tipo solo cuando quieras forzar uno distinto al inferido, o cuando declaras sin valor inicial:

```swift
let precio: Double = 10        // sin el ': Double' sería Int
var mensaje: String            // declarada ahora, asignada después
mensaje = "Listo"
```

<Callout type="warn" title="Swift no convierte tipos por ti">
A diferencia de otros lenguajes, Swift **no** mezcla tipos numéricos automáticamente. Sumar un `Int` y un `Double` da error; tienes que convertir explícitamente:

```swift
let a = 5           // Int
let b = 2.0         // Double
// let c = a + b    // ❌ error
let c = Double(a) + b   // ✅ conviertes a antes de sumar
```

Es más verboso, sí, pero elimina toda una clase de bugs sutiles de conversión.
</Callout>

## Interpolación de strings

Inserta valores dentro de un texto con `\(...)`:

```swift
let usuario = "William"
let mensajes = 5
print("Hola \(usuario), tienes \(mensajes) mensajes.")
// Hola William, tienes 5 mensajes.

// Puedes meter expresiones enteras:
print("El doble es \(mensajes * 2).")
```
