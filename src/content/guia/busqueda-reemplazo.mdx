## Buscar con patrones que no duelen

La sintaxis de regex de Vim es peculiar. El atajo es **"very magic"** (`\v`): hace que la regex se parezca a las de otros lenguajes, sin escapar tanto.

| Patrón | Significado |
|--------|-------------|
| `/\vfoo|bar` | very magic: `(`, `)`, `|`, `+` funcionan sin escape |
| `/\<palabra\>` | límites de palabra (coincide "palabra" entera) |
| `/foo\c` | ignora mayúsculas solo en esta búsqueda (`\C` las respeta) |
| `*` / `#` | busca la palabra bajo el cursor (adelante / atrás) |

### \zs y \ze: coincide, pero selecciona menos

`\zs` marca dónde **empieza** la coincidencia real y `\ze` dónde **termina**, aunque el patrón exija contexto alrededor:

```text
/foo\zsbar        → encuentra 'bar' solo si va tras 'foo' (pero selecciona 'bar')
/\vitem\ze:       → encuentra 'item' solo si va seguido de ':' (sin incluir ':')
```

Es la forma de decir "busca X en tal contexto, pero actúa solo sobre X".

## El truco estrella: cgn + .

`gn` selecciona la **siguiente** coincidencia de tu última búsqueda. Combinado con un operador, es oro:

<Callout type="dios" title="cgn: reemplazo interactivo sin comandos">
Busca una palabra con `*` (o `/palabra`). Ahora pulsa `cgn`, escribe el reemplazo y <KeyCap keys="Esc" />. Acabas de cambiar la primera aparición. Ve a la siguiente y pulsa `.` — repite el cambio. `n` para saltar una sin tocarla. Es buscar-y-reemplazar **con revisión**, sin escribir un solo `:s`, controlando cada ocurrencia con una tecla. Muchos expertos reemplazan así el 90% del tiempo.
</Callout>

<Drill reto="Renombra 'total' por 'suma' en un archivo, revisando cada aparición." teclas="*  cgn  suma  Esc  .  n  .">
`*` busca la palabra bajo el cursor. `cgn` cambia la siguiente coincidencia (escribe `suma`, <KeyCap keys="Esc" />). En la siguiente: `.` la repite, o `n` la salta. Avanzas ocurrencia a ocurrencia decidiendo cuál cambiar.
</Drill>

## :substitute con todo su poder

La forma general es `:{rango}s/patrón/reemplazo/{flags}`.

| Elemento | Ejemplo |
|----------|---------|
| Rango: archivo entero | `:%s/a/b/g` |
| Rango: selección visual | `:'<,'>s/a/b/g` |
| Flag confirmación | `:%s/a/b/gc` (pregunta en cada una) |
| Flag ignore-case | `:%s/a/b/gi` |
| Capturas | `:%s/\v(\w+)=(\w+)/\2=\1/` (intercambia) |
| Toda la coincidencia | `:%s/error/[&]/g` (envuelve en corchetes) |
| Cambiar caja | `:%s/\v<(\w)/\u\1/g` (pone mayúscula inicial) |

Los grupos `\1`, `\2`… reutilizan lo capturado con paréntesis. `&` es la coincidencia completa. `\u` / `\l` cambian a mayúscula/minúscula la siguiente letra; `\U` / `\L` hasta un `\E`.

<Callout type="tip" title="La /gc es tu amiga">
¿No te fías del patrón? Añade el flag `c`: Neovim se detiene en cada coincidencia y te pregunta (y=sí, n=no, a=todas, q=parar). Reemplazo masivo con confirmación, línea a línea, sin riesgo.
</Callout>

## Reemplazo en todo el proyecto

Dos caminos, según prefieras terminal o interfaz:

1. **quickfix + :cdo** (lección 4.4): `:grep patrón` y luego `:cdo s/.../.../g | update`. Control total desde el teclado.
2. **grug-far.nvim**: una interfaz dedicada de buscar-y-reemplazar en el proyecto, con vista previa en vivo de todos los cambios antes de aplicarlos.

```lua title="lua/plugins/grug-far.lua"
return {
  "MagicDuck/grug-far.nvim",
  cmd = "GrugFar",
  keys = {
    { "<leader>sr", function() require("grug-far").open() end, desc = "Buscar y reemplazar (proyecto)" },
  },
  opts = {},
}
```

1. Usa `\v` para buscar dos palabras alternativas en un archivo.
2. Con `\zs`, encuentra una palabra solo cuando va precedida de otra.
3. Renombra una variable con el flujo `*` → `cgn` → `.`.
4. Intercambia dos columnas separadas por `=` con `:%s/\v(\w+)=(\w+)/\2=\1/`.
5. Haz un reemplazo en todo el proyecto con grug-far o `:cdo`.
