<Lead>
LazyVim no es una caja negra: es la misma estructura que montaste a mano, con una base de plugins ya afinada encima. En cuanto veas dónde va cada cosa, la controlarás por completo.
</Lead>

<Objetivos>

- Instalar LazyVim de forma segura (con copia de seguridad).
- Entender su estructura de carpetas.
- Dominar el sistema de Extras (`:LazyExtras`).
- Saber dónde tocar para cada tipo de cambio.

</Objetivos>

## Instalación segura

<Callout type="warn" title="Haz copia de tu config actual">
LazyVim usa `~/.config/nvim`. Si ya tienes tu config a mano ahí, **guárdala** antes. Así puedes volver cuando quieras.
</Callout>

```bash
# 1) Copia de seguridad de tu config y datos actuales
mv ~/.config/nvim ~/.config/nvim.bak
mv ~/.local/share/nvim ~/.local/share/nvim.bak
mv ~/.local/state/nvim ~/.local/state/nvim.bak

# 2) Clona el starter oficial de LazyVim
git clone https://github.com/LazyVim/starter ~/.config/nvim

# 3) Quita el historial git del starter (para hacerlo tuyo)
rm -rf ~/.config/nvim/.git

# 4) Arranca: instalará todo solo
nvim
```

El primer arranque descarga e instala decenas de plugins. Cuando termine, reinicia Neovim y tendrás un IDE completo funcionando.

## La estructura (te sonará)

```text
~/.config/nvim/
├── init.lua                  # una línea: require("config.lazy")
├── lua/
│   ├── config/
│   │   ├── lazy.lua          # arranca LazyVim + tus imports de Extras
│   │   ├── options.lua       # TUS opciones (se fusionan con las de LazyVim)
│   │   ├── keymaps.lua       # TUS keymaps
│   │   └── autocmds.lua      # TUS autocmds
│   └── plugins/              # TUS specs: añadir, override o desactivar
└── lazy-lock.json            # versiones exactas (versiónalo en Git)
```

<Callout type="info" title="Es tu misma estructura del Nivel 1">
`lua/config` para opciones/keymaps/autocmds, `lua/plugins` para specs. Idéntico a lo que montaste a mano. La diferencia: LazyVim ya trae una base enorme, y tus archivos la **extienden o modifican**, no parten de cero.
</Callout>

## Cómo carga LazyVim

En `lua/config/lazy.lua`, LazyVim se importa como un plugin más y luego importa **tus** plugins y los Extras que actives:

```lua title="lua/config/lazy.lua (fragmento clave)"
require("lazy").setup({
  spec = {
    -- 1) la base de LazyVim
    { "LazyVim/LazyVim", import = "lazyvim.plugins" },

    -- 2) los Extras que actives (los añade :LazyExtras)
    { import = "lazyvim.plugins.extras.lang.typescript" },
    { import = "lazyvim.plugins.extras.lang.rust" },

    -- 3) TUS plugins (todo lo que pongas en lua/plugins/)
    { import = "plugins" },
  },
})
```

El orden importa: LazyVim primero, luego Extras, luego lo tuyo — así **lo tuyo siempre gana** y puede sobreescribir cualquier default.

## El sistema de Extras

Los **Extras** son módulos oficiales que añaden soporte de un lenguaje o una feature ya configurados y coordinados (LSP + formateador + linter + treesitter, todo junto). Se gestionan con una UI:

```vim
:LazyExtras
```

Se abre una lista navegable. Pulsa `x` sobre un extra para activarlo/desactivarlo; LazyVim edita tu `lua/config/lazy.lua` por ti añadiendo el `import`. Categorías típicas:

<div class="pill-row">
  <span class="pill"><b>lang.\*</b> lenguajes (rust, typescript, clangd…)</span>
  <span class="pill"><b>editor.\*</b> herramientas de edición</span>
  <span class="pill"><b>coding.\*</b> completado, snippets, pares</span>
  <span class="pill"><b>ai.\*</b> Copilot y compañía</span>
  <span class="pill"><b>ui.\*</b> mejoras de interfaz</span>
</div>

<Callout type="dios" title="Un IDE de Rust en 10 segundos">
Abre `:LazyExtras`, busca `lang.rust`, pulsa `x`, reinicia. Acabas de instalar rustaceanvim, crates.nvim, el debug y el formateo de Rust, todo coordinado y mantenido. Lo que en tu config a mano fue una lección entera, aquí es una tecla. Esa es la propuesta de valor de una distro bien hecha — y ahora entiendes exactamente qué está pasando por debajo.
</Callout>

<Reto title="Monta y explora">
1. Instala LazyVim con copia de seguridad previa.
2. Abre `:Lazy` y mira todo lo que trae de base.
3. Abre `:LazyExtras` y explora las categorías.
4. Activa `lang.typescript` y reinicia: ya tienes soporte de TS afinado.
5. Localiza dónde LazyVim añadió el `import` en `lua/config/lazy.lua`.
</Reto>
