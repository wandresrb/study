<Lead>
El LSP sabe qué autocompletar; blink.cmp lo muestra. Es el completado más rápido del ecosistema en 2026 (0.5–4 ms por pulsación), con fuzzy matching en Rust que perdona typos y fuentes integradas sin plugins extra.
</Lead>

<Objetivos>

- Por qué blink.cmp reemplazó a nvim-cmp como estándar.
- Instalarlo y conectarlo con tu LSP.
- Fuentes de completado, snippets y documentación flotante.
- Los atajos clave para aceptar, navegar y expandir.

</Objetivos>

## blink.cmp vs nvim-cmp

Durante años `nvim-cmp` fue el rey, pero requería ensamblar media docena de plugins de fuentes. **blink.cmp** llegó con otra filosofía: baterías incluidas y velocidad extrema.

| | blink.cmp | nvim-cmp |
|---|---|---|
| Velocidad | 0.5–4 ms/pulsación (motor Rust) | 2–50 ms, con debounce de 60 ms |
| Fuzzy | tolerante a typos (~6× fzf) | estilo fzf |
| Fuentes core | LSP, buffer, path, snippets **integradas** | externas, plugin por fuente |
| Setup | una spec | varias specs |

Para un setup nuevo en 2026, blink.cmp es la elección por defecto.

## Instalación

Crea `lua/plugins/completado.lua`:

```lua title="lua/plugins/completado.lua"
return {
  "saghen/blink.cmp",
  version = "1.*",  -- usa releases con el binario Rust precompilado
  dependencies = { "rafamadriz/friendly-snippets" },
  event = "InsertEnter",
  opts = {
    -- Preset de teclas: 'default', 'super-tab', 'enter'...
    keymap = { preset = "default" },

    appearance = { nerd_font_variant = "mono" },

    -- Orden y fuentes del completado
    sources = {
      default = { "lsp", "path", "snippets", "buffer" },
    },

    completion = {
      -- Documentación flotante automática
      documentation = { auto_show = true, auto_show_delay_ms = 200 },
      -- Vista previa "ghost text" del candidato
      ghost_text = { enabled = true },
      menu = { border = "rounded" },
    },

    -- Ayuda de firma de funciones mientras escribes los args
    signature = { enabled = true, window = { border = "rounded" } },

    fuzzy = { implementation = "prefer_rust_with_warning" },
  },
}
```

<Callout type="info" title="Recuerda las capabilities">
En la lección 2.1 añadiste `capabilities = require("blink.cmp").get_lsp_capabilities()` a la config de LSP. Eso le dice al servidor que tu cliente soporta completado avanzado (snippets, auto-import...). Sin ese paso, el completado es más pobre.
</Callout>

## Los atajos (preset default)

| Tecla | Acción |
|-------|--------|
| <KeyCap keys="Ctrl-Space" /> | abrir/cerrar el menú de completado |
| <KeyCap keys="Ctrl-y" /> | **aceptar** el candidato seleccionado |
| <KeyCap keys="Ctrl-n" /> / <KeyCap keys="Ctrl-p" /> | siguiente / anterior candidato |
| <KeyCap keys="Ctrl-e" /> | cancelar |
| <KeyCap keys="Ctrl-k" /> | mostrar signature help |
| <KeyCap keys="Tab" /> / <KeyCap keys="S-Tab" /> | saltar entre campos del snippet |

<Callout type="tip" title="¿Prefieres Tab para aceptar?">
Cambia `preset = "default"` por `preset = "super-tab"` y <KeyCap keys="Tab" /> aceptará el candidato (comportamiento tipo VS Code). El preset `"enter"` acepta con <KeyCap keys="Enter" />. Elige el que menos te haga pensar.
</Callout>

## Snippets

`friendly-snippets` te da una biblioteca enorme de snippets para casi todos los lenguajes, y blink.cmp los expone como una fuente más. Escribe el prefijo (p. ej. `fn`, `forr`, `useState`), acepta el candidato de snippet y salta entre los huecos con <KeyCap keys="Tab" />.

<Callout type="dios" title="El completado no es para escribir más rápido">
El valor real del completado no es teclear menos, es **descubrir la API**: al escribir `objeto.` ves todos los métodos disponibles con su documentación. Combinado con la ayuda de firma, editas lenguajes que apenas conoces sin salir del editor a buscar la doc. Ese es el bucle de un IDE de verdad.
</Callout>

<Reto title="Prueba el motor">
1. Crea `lua/plugins/completado.lua` y reinicia.
2. Abre un archivo con LSP activo y empieza a escribir: deberías ver el menú y el ghost text.
3. Escribe mal a propósito (`fuction`) y confirma que el fuzzy lo perdona.
4. Escribe un snippet (`fn` en Rust, `clg` en JS) y navega sus campos con <KeyCap keys="Tab" />.
5. Dentro de una llamada, pulsa <KeyCap keys="Ctrl-k" /> para ver la firma.

Con LSP + completado ya tienes la mitad de un IDE. Ahora afinamos la edición con Treesitter.
</Reto>
