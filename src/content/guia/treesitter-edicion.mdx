## Objetos de texto por sintaxis

Instala el módulo de objetos de texto de Treesitter. Amplía tu `lua/plugins/treesitter.lua` con una dependencia:

```lua title="lua/plugins/treesitter.lua (ampliado)"
return {
  "nvim-treesitter/nvim-treesitter",
  build = ":TSUpdate",
  event = { "BufReadPost", "BufNewFile" },
  dependencies = { "nvim-treesitter/nvim-treesitter-textobjects" },
  config = function()
    require("nvim-treesitter.configs").setup({
      ensure_installed = {
        "lua", "vim", "vimdoc", "c", "rust", "swift",
        "javascript", "typescript", "tsx", "html", "css",
        "json", "yaml", "toml", "markdown", "bash",
      },
      highlight = { enable = true },
      indent = { enable = true },
      incremental_selection = {
        enable = true,
        keymaps = {
          init_selection = "<C-space>",
          node_incremental = "<C-space>",
          node_decremental = "<bs>",
        },
      },
      textobjects = {
        select = {
          enable = true,
          lookahead = true,
          keymaps = {
            ["af"] = "@function.outer", ["if"] = "@function.inner",
            ["ac"] = "@class.outer",    ["ic"] = "@class.inner",
            ["aa"] = "@parameter.outer",["ia"] = "@parameter.inner",
            ["ai"] = "@conditional.outer", ["il"] = "@loop.inner",
          },
        },
        move = {
          enable = true,
          goto_next_start = { ["]f"] = "@function.outer", ["]a"] = "@parameter.inner" },
          goto_previous_start = { ["[f"] = "@function.outer" },
        },
      },
    })
  end,
}
```

Ahora tienes objetos nuevos que combinan con los verbos del Nivel 0:

<div class="pill-row">
  <span class="pill"><b>dif</b> borra el cuerpo de la función</span>
  <span class="pill"><b>yaf</b> copia la función entera</span>
  <span class="pill"><b>cia</b> cambia un argumento</span>
  <span class="pill"><b>vac</b> selecciona la clase</span>
  <span class="pill"><b>]f</b> salta a la siguiente función</span>
</div>

## Selección incremental

Pon el cursor en cualquier sitio y pulsa <KeyCap keys="Ctrl-Space" /> repetidamente: la selección crece nodo a nodo por el árbol de sintaxis (identificador → expresión → argumento → llamada → sentencia → bloque). <KeyCap keys="Backspace" /> la reduce. Es la forma más intuitiva de seleccionar exactamente lo que quieres.

## flash.nvim: saltar a cualquier parte

`f`/`t` saltan dentro de la línea. **flash.nvim** salta a cualquier punto visible con 2-3 teclas: pulsas `s`, escribes un par de caracteres del destino y aparecen etiquetas para saltar ahí.

```lua title="lua/plugins/flash.lua"
return {
  "folke/flash.nvim",
  event = "VeryLazy",
  opts = {},
  keys = {
    { "s", mode = { "n", "x", "o" }, function() require("flash").jump() end, desc = "Flash" },
    { "S", mode = { "n", "x", "o" }, function() require("flash").treesitter() end, desc = "Flash Treesitter" },
  },
}
```

<PluginCard name="flash.nvim" repo="folke/flash.nvim" tag="core" icon="⚡">
Navegación por saltos con etiquetas. `s` + 2 letras y estás en cualquier parte de la pantalla. Reemplaza a EasyMotion/Hop.
</PluginCard>

## mini.nvim: surround, pairs, comentarios

`mini.nvim` es una colección de módulos pequeños y sólidos. Tres son imprescindibles:

```lua title="lua/plugins/mini.lua"
return {
  { "echasnovski/mini.surround", version = false, event = "VeryLazy", opts = {} },
  { "echasnovski/mini.pairs",    version = false, event = "InsertEnter", opts = {} },
  { "echasnovski/mini.ai",       version = false, event = "VeryLazy", opts = {} },
}
```

<Cards>
  <Card icon="🎁" title="mini.surround">
    Añade, cambia o quita delimitadores: `saiw"` rodea una palabra con comillas, `sd"` las quita, `sr"'` cambia `"` por `'`.
  </Card>
  <Card icon="🔗" title="mini.pairs">
    Cierra automáticamente paréntesis, comillas y llaves.
  </Card>
  <Card icon="🎯" title="mini.ai">
    Mejora los objetos de texto: `ci)` funciona aunque el paréntesis esté lejos, y añade objetos por Treesitter.
  </Card>
</Cards>

Para comentar, Neovim 0.11 ya trae `gc` nativo: `gcc` comenta la línea, `gcap` un párrafo, `gc` en Visual la selección. No necesitas plugin.

## Autotag para JSX/HTML

Al escribir frontend, cerrar y renombrar etiquetas a mano es tedioso. `nvim-ts-autotag` lo automatiza con Treesitter:

```lua title="lua/plugins/autotag.lua"
return {
  "windwp/nvim-ts-autotag",
  ft = { "html", "javascriptreact", "typescriptreact", "tsx", "vue", "svelte", "xml" },
  opts = {},
}
```

Escribe `<div>` y se cierra solo; renombra la etiqueta de apertura y la de cierre se actualiza sola.

<Callout type="dios" title="La suma es el superpoder">
Combina todo: `S` (flash) para saltar a una función lejana, `vaf` para seleccionarla, `saf)` no — mejor `cif` para reescribir su cuerpo, `]a` para saltar entre argumentos. Cuando estos reflejos se encadenan sin pensar, editas más rápido de lo que la mayoría lee. Esa fluidez es, literalmente, el nivel dios.
</Callout>

<Reto title="Edición por estructura">
Abre un archivo con funciones y clases:

1. `Ctrl-Space` repetido para seleccionar por nodos crecientes.
2. `dif` para vaciar una función; `u` para deshacer.
3. `s` + 2 letras (flash) para saltar al otro extremo del archivo.
4. `saiw)` para rodear una palabra con paréntesis; `sd)` para quitarlos.
5. `]f` / `[f` para navegar entre funciones.
</Reto>
