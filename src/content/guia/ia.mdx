<Lead>
La IA potencia Neovim, pero mal integrada es un caos de plugins peleándose. La clave, según la comunidad en 2026, es pensar en capas y usar exactamente una herramienta por capa. Así montas un flujo con IA que suma en vez de estorbar.
</Lead>

<Objetivos>

- Entender las tres capas de IA y elegir una por capa.
- Completado fantasma (ghost text) con Copilot o Supermaven.
- Chat y edición multi-línea con CodeCompanion o Avante.
- Agentes de terminal (Claude Code) dentro de Neovim vía sidekick.

</Objetivos>

<Callout type="warn" title="Una herramienta por capa">
No instales dos plugins de ghost text a la vez: pelearán por la misma tecla y el mismo espacio visual. Elige uno por capa y tendrás un flujo limpio.
</Callout>

## Capa 1 — Completado fantasma

Sugerencias inline mientras escribes, que aceptas con una tecla. Opciones: **copilot.lua** (GitHub Copilot), **Supermaven** (rapidísimo), **Minuet** (multi-proveedor, permite local con Ollama), **NeoCodeium**.

```lua title="lua/plugins/ai-copilot.lua"
return {
  "zbirenbaum/copilot.lua",
  cmd = "Copilot",
  event = "InsertEnter",
  opts = {
    suggestion = {
      auto_trigger = true,
      keymap = {
        accept = "<C-l>",     -- acepta la sugerencia fantasma
        next = "<C-]>",
        dismiss = "<C-h>",
      },
    },
    panel = { enabled = false },
  },
}
```

<Callout type="tip" title="¿Privacidad o velocidad?">
Si no quieres mandar código a la nube, usa **Minuet + Ollama** con un modelo local (p. ej. `qwen2.5-coder`). Si priorizas latencia mínima, **Supermaven** es asombrosamente rápido. Copilot es el estándar equilibrado.
</Callout>

## Capa 2 — Edición multi-línea y chat

Para "reescribe esta función", "explícame este error" o refactors de un bloque entero. Los dos grandes en 2026: **CodeCompanion** (estable, integradísimo) y **Avante** (estilo Cursor, con diffs).

```lua title="lua/plugins/ai-chat.lua"
return {
  "olimorris/codecompanion.nvim",
  dependencies = { "nvim-lua/plenary.nvim", "nvim-treesitter/nvim-treesitter" },
  opts = {
    strategies = {
      chat = { adapter = "anthropic" },
      inline = { adapter = "anthropic" },
    },
  },
  keys = {
    { "<leader>ac", "<cmd>CodeCompanionChat Toggle<cr>", mode = { "n", "v" }, desc = "IA: chat" },
    { "<leader>ai", "<cmd>CodeCompanion<cr>", mode = { "n", "v" }, desc = "IA: edición inline" },
    { "<leader>aa", "<cmd>CodeCompanionActions<cr>", mode = { "n", "v" }, desc = "IA: acciones" },
  },
}
```

<Callout type="info" title="Configura tu proveedor">
CodeCompanion y Avante soportan varios adaptadores (Anthropic/Claude, OpenAI, Copilot, Gemini, Ollama). Exporta tu clave como variable de entorno (p. ej. `ANTHROPIC_API_KEY`) antes de arrancar Neovim, o reutiliza tu suscripción de Copilot como backend.
</Callout>

Flujo típico: selecciona código en modo Visual, `<leader>ai`, describe el cambio ("añade manejo de errores"), y revisa el diff antes de aceptarlo. Para preguntas abiertas, `<leader>ac` abre un chat con el contexto de tu buffer.

## Capa 3 — Agentes CLI (Claude Code) dentro de Neovim

Los agentes de terminal como **Claude Code** trabajan sobre todo el proyecto (leen y editan varios archivos, corren comandos). **sidekick.nvim** (de folke) los integra dentro de Neovim: un panel con el agente, envío de contexto (selección, diagnósticos, el buffer) y aceptación de cambios sin salir del editor.

```lua title="lua/plugins/ai-sidekick.lua"
return {
  "folke/sidekick.nvim",
  opts = {
    cli = {
      mux = { backend = "zellij", enabled = true }, -- o "tmux"
    },
  },
  keys = {
    { "<leader>as", function() require("sidekick.cli").toggle() end, desc = "Sidekick: agente" },
    { "<leader>ap", function() require("sidekick.cli").prompt() end, mode = { "n", "v" }, desc = "Sidekick: prompt con contexto" },
    {
      "<Tab>",
      function()
        if not require("sidekick").nes_jump_or_apply() then return "<Tab>" end
      end,
      expr = true,
      desc = "Sidekick: aplicar next-edit o Tab",
    },
  },
}
```

<PluginCard name="sidekick.nvim" repo="folke/sidekick.nvim" tag="ai" icon="🤝">
Integra agentes CLI (Claude Code, etc.) y las "next edit suggestions" del LSP de Copilot. El puente entre los agentes de terminal y tu editor.
</PluginCard>

<Callout type="dios" title="La IA como copiloto, no como piloto">
El nivel dios con IA no es aceptar todo lo que sugiere: es dirigirla. Ghost text para lo trivial, edición inline para refactors acotados que **revisas**, y el agente para tareas grandes que supervisas. Tú sigues siendo quien entiende el código y toma las decisiones; la IA elimina el tecleo mecánico. Quien delega el criterio pierde; quien delega el trabajo repetitivo, vuela.
</Callout>

<Reto title="Monta tu stack de IA">
1. Elige **una** herramienta por capa (p. ej. Copilot + CodeCompanion + sidekick).
2. Acepta una sugerencia fantasma con tu tecla de accept.
3. Selecciona una función y pídele a la capa 2 que le añada tests; revisa el diff.
4. Abre el agente con `<leader>as` y pídele una tarea multi-archivo pequeña.
5. Comprueba que ninguna herramienta pelea con otra por las mismas teclas.
</Reto>
