<Lead>
Neovim no vive aislado: vive en tu terminal. Un usuario de nivel dios afina todo el entorno — el shell, el prompt, las herramientas de línea de comandos y el buscador difuso — hasta que moverse por cualquier proyecto es instantáneo.
</Lead>

<Objetivos>

- Un shell moderno con prompt informativo (starship).
- Las CLI modernas que reemplazan a `ls`, `cd`, `cat`, `grep`.
- El buscador difuso dentro de Neovim con snacks.nvim.
- Terminal integrada sin salir del editor.

</Objetivos>

## Shell y prompt

Usa **zsh** (por defecto en macOS) o **fish**, y ponles **starship**: un prompt rapidísimo que muestra rama de Git, versión de lenguaje, estado del comando anterior y más.

```bash
brew install starship
# zsh: añade al final de ~/.zshrc
echo 'eval "$(starship init zsh)"' >> ~/.zshrc
```

## Las CLI modernas (reemplazos directos)

Estas herramientas son más rápidas y bonitas que las clásicas. Muchas ya las instalaste; complétalas:

```bash
brew install eza zoxide bat fd ripgrep fzf git-delta
```

<Cards>
  <Card icon="📂" title="eza → ls">
    Listados con iconos, colores y Git. Alias: `alias ls='eza --icons --git'`.
  </Card>
  <Card icon="🧭" title="zoxide → cd">
    Salta a carpetas por frecuencia: `z proj` te lleva a tu proyecto sin la ruta completa.
  </Card>
  <Card icon="🦇" title="bat → cat">
    Muestra archivos con resaltado de sintaxis y números de línea.
  </Card>
  <Card icon="🔎" title="ripgrep → grep">
    Búsqueda de texto ultrarrápida, respeta `.gitignore`. Motor del grep de Neovim.
  </Card>
  <Card icon="📁" title="fd → find">
    Búsqueda de archivos simple y veloz.
  </Card>
  <Card icon="🌸" title="fzf">
    Selector difuso universal para el shell: `Ctrl-r` (historial), `Ctrl-t` (archivos).
  </Card>
</Cards>

```bash title="~/.zshrc (fragmento)"
eval "$(zoxide init zsh)"
alias ls='eza --icons --git'
alias cat='bat'
alias cd='z'
export FZF_DEFAULT_COMMAND='fd --type f --hidden --exclude .git'
```

## El buscador difuso dentro de Neovim

Aquí está una de las piezas más importantes de todo el setup: el **picker**, cómo abres archivos y buscas texto en el proyecto sin árboles ni ratón. En 2026 hay tres grandes opciones: **Telescope** (el clásico), **fzf-lua** (velocísimo) y **snacks.nvim** (la suite de folke, con picker + explorador + terminal + dashboard). Usaremos snacks: moderno, integradísimo y una sola dependencia.

```lua title="lua/plugins/snacks.lua"
return {
  "folke/snacks.nvim",
  priority = 1000,
  lazy = false,
  opts = {
    picker = { enabled = true },
    explorer = { enabled = true },
    terminal = { enabled = true },
    dashboard = { enabled = true },
    indent = { enabled = true },
    notifier = { enabled = true },
  },
  keys = {
    { "<leader>ff", function() Snacks.picker.files() end, desc = "Buscar archivos" },
    { "<leader>fg", function() Snacks.picker.grep() end, desc = "Grep en el proyecto" },
    { "<leader>fb", function() Snacks.picker.buffers() end, desc = "Buffers abiertos" },
    { "<leader>fr", function() Snacks.picker.recent() end, desc = "Archivos recientes" },
    { "<leader>fs", function() Snacks.picker.lsp_symbols() end, desc = "Símbolos del archivo" },
    { "<leader>fd", function() Snacks.picker.diagnostics() end, desc = "Diagnósticos" },
    { "<leader>e",  function() Snacks.explorer() end, desc = "Explorador de archivos" },
    { "<leader>tt", function() Snacks.terminal() end, desc = "Terminal flotante" },
  },
}
```

<PluginCard name="snacks.nvim" repo="folke/snacks.nvim" tag="core" icon="🍿">
Suite de calidad de vida: picker con 40+ fuentes, explorador, terminal flotante, dashboard, notificaciones e indent guides. Reemplaza media docena de plugins.
</PluginCard>

<Callout type="tip" title="Los tres atajos que más usarás">
`<leader>ff` (archivos), `<leader>fg` (grep en todo el proyecto) y `<leader>fb` (buffers). Interiorízalos primero: son la forma más rápida de saltar a cualquier sitio en cualquier proyecto. El árbol de archivos (`<leader>e`) es secundario — los pros navegan buscando, no clicando.
</Callout>

## Terminal integrada

Neovim trae una terminal nativa (`:terminal`). snacks la mejora con una flotante en `<leader>tt`. Recuerda: para salir del modo Terminal a Normal, pulsa <KeyCap keys="Ctrl-\ Ctrl-n" /> (o mapea algo más cómodo).

<Callout type="dios" title="El proyecto entero a un par de teclas">
El objetivo: abres el terminal en cualquier carpeta, `z proyecto` te lleva, `nvim` arranca, `<leader>ff` encuentra el archivo, `<leader>fg` busca esa función que recuerdas a medias. Desde teclear hasta editar la línea correcta pasan menos de tres segundos. Cuando ese flujo es automático, la fricción entre tu intención y el código desaparece.
</Callout>

<Reto title="Afina el entorno">
1. Instala starship y las CLI modernas; añade los alias a tu shell.
2. Prueba `z` (zoxide) para saltar a un proyecto reciente.
3. Añade snacks.nvim y prueba `<leader>ff` y `<leader>fg`.
4. Abre la terminal flotante con `<leader>tt` y sal con <KeyCap keys="Ctrl-\ Ctrl-n" />.
</Reto>
