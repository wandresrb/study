## Activar los Extras de lenguaje

Abre `:LazyExtras` y activa (tecla `x`) los que necesites, o añádelos a mano en `lua/config/lazy.lua`:

```lua title="lua/config/lazy.lua (imports de Extras)"
spec = {
  { "LazyVim/LazyVim", import = "lazyvim.plugins" },

  -- Nuestros stacks
  { import = "lazyvim.plugins.extras.lang.clangd" },      -- C / C++
  { import = "lazyvim.plugins.extras.lang.rust" },        -- Rust (rustaceanvim + crates)
  { import = "lazyvim.plugins.extras.lang.typescript" },  -- TS / JS
  { import = "lazyvim.plugins.extras.lang.tailwind" },    -- Tailwind
  { import = "lazyvim.plugins.extras.lang.json" },
  { import = "lazyvim.plugins.extras.formatting.prettier" },

  -- IA
  { import = "lazyvim.plugins.extras.ai.copilot" },

  { import = "plugins" },
},
```

Cada Extra trae **todo coordinado**, exactamente lo que montaste a mano en el Nivel 2:

<Cards>
  <Card icon="🔵" title="lang.clangd">
    clangd + su formateo. Recuerda generar `compile_commands.json` (lección 2.5).
  </Card>
  <Card icon="🦀" title="lang.rust">

  </Card>

## Swift: el que va a mano

LazyVim no trae un Extra oficial de Swift, así que lo añadimos nosotros — reutilizando lo de la lección 2.7. Un archivo en `lua/plugins/`:

```lua title="lua/plugins/lang-swift.lua"
return {
  {
    "neovim/nvim-lspconfig",
    opts = function()
      vim.lsp.config("sourcekit", {
        cmd = { "xcrun", "sourcekit-lsp" },
        filetypes = { "swift", "objc", "objcpp" },
        root_markers = { "Package.swift", ".git", "buildServer.json" },
      })
      vim.lsp.enable("sourcekit")
    end,
  },
  -- formateo swift-format vía conform (LazyVim ya trae conform)
  {
    "stevearc/conform.nvim",
    opts = { formatters_by_ft = { swift = { "swift_format" } } },
  },
}
```

<Callout type="info" title="El patrón para cualquier lenguaje sin Extra">
Este archivo es la plantilla universal: reabres `nvim-lspconfig` con `opts` para habilitar el servidor, y `conform` con `opts` para el formateo. Sirve para Swift, Zig, Gleam o cualquier lenguaje que LazyVim no cubra con un Extra. Sabes hacerlo porque entiendes el Nivel 2.
</Callout>

## IA sobre LazyVim

El Extra `ai.copilot` activa Copilot para ghost text. Si prefieres el stack por capas de la lección 3.4 (Supermaven, CodeCompanion, sidekick), añádelos como plugins propios en `lua/plugins/` — se integran igual que en tu config a mano.

<Callout type="dios" title="Lo mejor de los dos mundos">
Fíjate en lo que acabas de hacer: la comodidad de los Extras para lo estándar (C, Rust, TS, Tailwind, Copilot) **y** tu conocimiento del Nivel 2 para lo que la distro no cubre (Swift, tu stack de IA a medida). Un usuario que solo sabe distros se estanca cuando falta un Extra. Tú no: puedes construir la pieza que falte y encajarla. Eso es ser Arquitecto.
</Callout>
