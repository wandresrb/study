Esa frase dejó de ser cierta en abril de 2025 y sigue circulando como si nada hubiera pasado, con el resultado de que equipos enteros descartan la herramienta por una restricción que ya no existe, o peor, reimplementan a mano cosas que tienen delante y gratis. ## El hecho, con fecha

**En abril de 2025, Webflow adquirió GreenSock y liberó GSAP entero.** La biblioteca completa —núcleo y todos los plugins, incluidos los que antes formaban parte del Club GreenSock— pasó a ser gratuita para todo el mundo, con el uso comercial cubierto. El equipo original de GSAP sigue manteniendo la librería, ahora trabajando a tiempo completo en Webflow.

No es una versión "community" recortada, ni una licencia gratuita solo para proyectos personales, ni un plan gratuito con límites. Es la biblioteca entera, para cualquier uso, incluidos productos comerciales, agencias facturando a clientes y proyectos que se venden a terceros.

Los plugins que antes eran de pago y ahora no lo son:

| Plugin | Qué hace |
|---|---|
| ScrollTrigger | Dispara y sincroniza animaciones con el scroll |
| ScrollSmoother | Scroll suavizado con efectos de profundidad |
| SplitText | Divide texto en líneas, palabras y caracteres animables |
| MorphSVG | Interpola entre dos formas SVG arbitrarias |
| DrawSVG | Anima el dibujado de un trazo |
| MotionPathHelper | Editor visual de trayectorias en la propia página |
| Flip | Animaciones entre estados de layout imposibles de interpolar |
| Inertia | Movimiento con inercia tras soltar un gesto |
| ScrambleText | Efecto de texto que se descifra |
| Physics2D y PhysicsProps | Movimiento con aceleración, gravedad y fricción |
| CustomEase, CustomBounce, CustomWiggle | Curvas de easing definidas por ti |
| GSDevTools | Panel de control para inspeccionar y depurar timelines |

Draggable, Observer, MotionPath, ScrollTo, Text y los plugins de integración con Pixi y EaselJS ya eran gratuitos antes y lo siguen siendo.

<Callout type="warn" title="Lo que la vieja narrativa dice y ya no es cierto">
Si encuentras un artículo, un hilo de foro o una respuesta generada que diga cualquiera de estas cosas, está desactualizado: que hace falta una suscripción al Club GreenSock para ScrollTrigger o SplitText; que MorphSVG es de pago; que el uso comercial requiere licencia; que los plugins de pago viven en un repositorio npm privado al que hay que autenticarse. Las cuatro afirmaciones fueron ciertas hasta abril de 2025 y ninguna lo es hoy.
</Callout>

## El repositorio privado ya no existe

El cambio con consecuencias operativas es este: **el repositorio npm privado dejó de mantenerse y todos los plugins están en el paquete público `gsap` de npm**. Si tu proyecto arrastra un `.npmrc` con una referencia a `npm.greensock.com`, esa configuración apunta a un sitio que ya no se mantiene, y la instalación funcionará solo mientras el registro siga en pie.

La migración es quitar la configuración antigua y asegurarse de estar en una versión suficientemente reciente:

```bash
# 1. Elimina la configuracion del registro privado.
rm .npmrc          # o borra solo la linea de npm.greensock.com

# 2. Reinstala desde el registro publico.
npm uninstall gsap
npm install gsap

# 3. Comprueba la version. Los plugins estan en el paquete
#    publico a partir de la 3.13; hoy la rama activa es la 3.15.
npm ls gsap
```

Los plugins que antes eran de pago tenían el prefijo `Club` en algunos ejemplos y rutas de importación específicas; hoy todos se importan del mismo paquete con la misma forma:

```js
import { gsap } from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';
import { SplitText } from 'gsap/SplitText';
import { MorphSVGPlugin } from 'gsap/MorphSVGPlugin';
import { DrawSVGPlugin } from 'gsap/DrawSVGPlugin';

gsap.registerPlugin(ScrollTrigger, SplitText, MorphSVGPlugin, DrawSVGPlugin);
```

Ese bloque funciona con una instalación limpia de `npm install gsap` y nada más. No hay token, no hay registro alternativo, no hay paso de autenticación.

## Qué sigue costando dinero

La honestidad exige la otra mitad. La **biblioteca** es gratis; lo que puede costar dinero son cosas que no son la biblioteca.

El foro de soporte, la comunidad y la documentación son gratuitos y públicos. Los cursos y materiales de formación de terceros —que existen y son buenos— siguen siendo de pago porque nunca fueron de GreenSock. Y Webflow, la empresa que ahora mantiene GSAP, es un producto comercial: usar GSAP no te obliga a nada respecto a Webflow, pero es evidente que la adquisición responde a una estrategia de plataforma y no a filantropía. Merece la pena tenerlo presente al valorar la sostenibilidad a largo plazo, igual que con cualquier herramienta mantenida por una empresa.

La licencia concreta que acompaña al paquete es la que figura en el repositorio y en el propio npm, y conviene leerla si tu organización tiene un proceso de revisión de licencias; el resumen operativo —uso comercial cubierto, sin cuota— es el que hemos visto, pero un equipo legal querrá el texto y no un resumen.

<Callout type="dios" title="El coste de haber sido de pago no se ha ido del todo">
Quince años de licencia de pago dejaron un poso técnico que sigue causando problemas y que nadie relaciona con la licencia. El primero: hay muchísimo código de ejemplo en internet escrito contra versiones antiguas, con rutas de importación que ya no son las canónicas y con nombres de plugin que cambiaron. El segundo, y más molesto: durante la época del repositorio privado se popularizaron **copias no oficiales de los plugins de pago** subidas a npm por terceros, con nombres parecidos y sin mantenimiento. Siguen ahí, siguen apareciendo en resultados de búsqueda y son ahora completamente innecesarias, pero un `npm install` con un nombre mal copiado te mete en el proyecto una versión de 2021 con bugs que se arreglaron hace años. Regla simple: **si una importación de GSAP no viene del paquete `gsap`, está mal**. Ese paquete y ninguno más.
</Callout>
